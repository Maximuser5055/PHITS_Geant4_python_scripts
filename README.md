# PHITS and Geant4 Automation Scripts

**Author:** Clarence Albert S. Feliciano  
**Degree:** MS Medical Physics  
**Institution:** University of the Philippines Manila

## Description

This repository contains the Python scripting and other input files

Most of the code was generated with the assistance of large language models (LLMs), except for the Geant4 dosimetry code templates provided in the supplemental files of ICRP 145 (https://www.icrp.org/publication.asp?id=ICRP%20Publication%20145). However, the results were manually verified by the author.
